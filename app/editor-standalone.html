Editor project

The project JSON stores all 100 physical level records, all 80 oddtable records, campaign slot assignments and the editable difficulty-group sequence. Original graphics are not copied into it; reload the source LHA, disk image or extracted data to render.

Raw exports

These are writer-side validation outputs. They are uncompressed; replacing the original ByteKiller-compressed Amiga files directly with these exports will not work yet.

Special levels: v0.13 can assign any of the four existing Amiga special backdrops to another physical level. The project format deliberately leaves room for additional special assets later, but adding a fifth unique specialX file to the original game requires the Amiga loader/table limit to be proved and, if necessary, patched.
WHDLoad testing direction: the current Lemmings v1.5 WHDLoad install supports either disk images or real files. The editor can now read both packaging styles. Writing playable replacements still needs a compatible ByteKiller/packed-file writer; after that, the cleanest first test path is likely the WHDLoad real-files install, with regenerated disk images as a second export target.
